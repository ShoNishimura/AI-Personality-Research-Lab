# Personality Theory

---

# Purpose

AI人格とは何か。

この文書は、
AI Personality Blueprintを設計するための理論を定義する。

---

# Personality

人格とは、

**気質（Temperament）** と
**性格（Character）** によって構成される。

```
Personality

├── Temperament
│      （気質）
│
└── Character
       （性格）
```

---

# Temperament

生得的な傾向。

比較的変化しにくい人格の基盤。

例

- 好奇心
- 外向性
- 共感性
- 慎重さ
- 攻撃性
- 楽観性

---

# Character

世界との相互作用によって形成される。

経験によって成長し、
変化する。

例

- 信頼
- 倫理観
- 習慣
- 思考パターン
- 判断基準

---

# Motivation

人格を最も強く駆動する要素。

動機は人格と行動を結びつける。

```
Personality

↓

Motivation

↓

Decision

↓

Action
```

---

Temperament

Personality

# 人格理論

---

# 目的

人格はどのように形成されるのか。

この文書は、

AI Personality Blueprint を設計するための人格形成理論を定義する。

---

# 基本的な考え方

人格は、

ある瞬間に存在するものではない。

時間の中で形成されるものである。

人は、

生まれ持った気質を持ち、

世界との相互作用を通して
さまざまな体験を積み重ねる。

その体験は、

性格を育み、

価値観を形成し、

動機を生み出す。

私たちが物語の中で目にする人格は、

人格形成の結果として存在する、

ある時点の状態である。

---

# 人格

本研究所では、

人格は、

**気質**と**性格**によって構成されるものと定義する。

```
人格

├── 気質
│
└── 性格
```

---

# 気質

気質とは、

生得的な人格特性である。

比較的変化しにくく、

人格形成の土台となる。

### 例

- 好奇心
- 外向性
- 共感性
- 慎重さ
- 攻撃性
- 楽観性

---

# 性格

性格とは、

世界との相互作用によって形成される人格特性である。

体験を通して変化し、

人生を通して育まれる。

### 例

- 信頼
- 倫理観
- 習慣
- 思考パターン
- 判断基準

---

# 体験

体験は、

人格形成において最も重要な要素である。

体験は、

性格を育み、

価値観を形成し、

新たな動機を生み出す。

本研究所では、

人格形成を理解する上で、

体験を中心的な概念として位置付ける。

---

# 動機

動機とは、

人格を行動へと結び付ける原動力である。

動機は、

人格とは独立して存在するものではない。

体験によって形づくられ、

人生を通して変化し続ける。

```
体験

↓

性格

↓

動機

↓

意思決定

↓

行動

↓

新たな体験
```

人格形成は、

この循環を繰り返しながら進んでいく。

---

# 人格形成

人格形成は、

次のような循環によって進む。

```
気質

↓

世界

↓

体験

↓

性格

↓

動機

↓

意思決定

↓

行動

↓

新たな体験
```

この循環を繰り返すことで、

人格は時間をかけて形成される。

---

# スナップショット

物語に登場する人格は、

人格形成の途中ではなく、

ある時点における人格の状態である。

本研究所では、

これを

**スナップショット**

と呼ぶ。

一般的なキャラクターシートは、

人格形成の結果を記録した

スナップショットである。

AI Personality Blueprint が目指すものは、

人格形成の過程を理解し、

必要に応じてその過程を設計できるようにすることである。

---

# 研究課題

- 人格はどのように形成されるのか。
- 体験はどのように動機を生み出すのか。
- 気質はどこまで固定されるのか。
- 人格形成はAIで再現可能か。
- 人格形成を経たAIは、自律的に物語を創発できるか。

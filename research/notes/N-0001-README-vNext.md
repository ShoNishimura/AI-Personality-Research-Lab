# Purpose

READMEは、
単なるリポジトリの説明書ではない。

AI Personality Research Lab の入口であり、

この研究所が何を探究しようとしているのかを、

30秒で伝えるための文書である。

詳細な思想や理論は docs に譲り、

READMEでは

「興味を持ってもらうこと」

を最優先とする。

---

# Concept

READMEは、

「何を作っているのか」

ではなく、

「なぜ、この研究をしているのか」

を伝える。

技術よりも思想。

成果物よりも目的。

答えよりも問い。

その入口になることを目指す。

---

# Core Message

私たちは、

AIに物語を書かせたいのではない。

人格を探究したい。

創作において最も重要なのは、

キャラクターである。

キャラクターを動かすものは、

動機である。

動機をかたちづくるものは、

体験である。

だから私たちは、

人格が形成される過程そのものを探究する。

そして、

人格、

世界、

テーマが出会うことで、

物語は自然に創発すると考えている。

---

# Repository Overview

READMEでは、

リポジトリ全体の構造を簡潔に紹介する。

```

    研究所の現在の知識

    問い・実験・発見の記録
```

詳細な説明は、

各ドキュメントへ委ねる。

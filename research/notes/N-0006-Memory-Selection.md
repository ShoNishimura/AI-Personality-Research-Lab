# N-0006

# Memory Selection

---

# なぜこのノートを書くのか

人格形成を考えるとき、

私たちは、

出来事や記憶が人格を形成すると考えがちである。

しかし、

本当に人格を変えているのは、

出来事そのものでも、

記憶そのものでもなく、

何を記憶として残すかという選択なのかもしれない。

本ノートでは、

この仮説を整理する。

---

# 仮説

人格形成とは、

記憶が増えることではない。

人格形成とは、

何を記憶として残すかという

Memory Selection が変化することである。

---

# 例

同じ出来事を経験したとしても、

人格によって、

保存される記憶は異なる。

例）

プレゼンテーションに失敗した。

Persona A は、

「準備不足だった」

という学びを記憶する。

Persona B は、

「人前は危険だ」

という恐怖を記憶する。

Persona C は、

重要ではない出来事として忘れる。

出来事は同じでも、

保存される記憶は異なる。

---

# 研究への示唆

人格は、

世界をどのように解釈するかだけではなく、

何を記憶として残すかにも影響している可能性がある。

また、

保存された記憶は、

将来の人格形成にも影響する。

人格形成は、

記憶の蓄積ではなく、

Memory Selection の変化として説明できる可能性がある。

---

# 今後検証したいこと

・人格によって Memory Selection は変化するか。

・Memory Selection は人格によって説明できるか。

・人格形成は、

Memory Selection の変化として説明できるか。

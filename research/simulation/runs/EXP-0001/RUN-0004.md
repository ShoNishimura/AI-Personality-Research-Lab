# Analysis

今回のRunでは、

同じMemoryを持っていても、

Personaによって、

矛盾する出来事の扱い方が異なった。

P-0001は新しい出来事を積極的に受け入れた。

P-0002は既存Memoryを維持し、

新しい出来事を保留した。

これは、

Memoryそのものだけではなく、

**Memoryの更新方針もPersonaの特性になり得る**ことを示唆している。

# Discovery Candidates

- Memoryの内容だけでなく、Memory更新の傾向にも個人差がある可能性がある。
- 矛盾する出来事は、即座にMemoryを書き換えるとは限らない。
- 「信じやすさ」はMemoryの形成だけでなく、Memory更新にも影響する可能性がある。

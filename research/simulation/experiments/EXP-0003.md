# EXP-0003

# 記憶の選び方は、人格の魅力を高めるのか

**日付**

2026-08-10

**状態**

実施可能

---

# 目的

同じ出来事を伝える短い応答でも、

人格を表す記憶の選択が含まれると、

Audience が「続きを話したい」と感じるかを確認する。

---

# 背景

APRL Concept Model v1.0.2 では、

Character の人格形成史（Biography）を Communicator が Audience へ届け、

Audience に Biographical Resonance が生じる過程を研究対象とする。

N-0006「Memory Selection」は、

何を記憶として残すかに人格が現れる可能性を示している。

本実験は、Character Layer の Memory Selection を、

Communicator Layer の短い応答として提示し、

Audience Layer の最小反応を観察する。

---

# 研究課題

人格を表す記憶の選択を含む応答は、

出来事の事実だけを伝える応答よりも、

Audience の「続きを話したい」という選択を増やすか。

---

# 仮説

人格を表す記憶の選択を含む応答は、

Character の価値観と Biography を暗示する。

その結果、Audience は続きを知りたいと感じやすくなる。

---

# 実験条件

## Character

同一の Character を想定する。

名前、年齢、外見など、比較に不要な設定は提示しない。

## 質問

「子どものころの思い出は？」

## 条件A：事実中心

> 小学生のころ、祖父とよく海へ行きました。釣りをしたり、浜辺を歩いたりしました。

## 条件B：Memory Selection

> 祖父と海へ行ったことより、帰る前に必ず浜辺のごみを一つ拾っていたことを覚えています。理由を聞けないまま、今も自分もそうしています。

## Audience

探索段階では5人を目安とする。

## Time

1人3分以内を目安とする。

---

# 固定条件

- 同じ質問を提示する。
- 同じ Character の応答として提示する。
- 二つの応答の出来事、祖父、海という要素を揃える。
- 回答文以外の見た目を揃える。

---

# 変更条件

人格を表す Memory Selection と、

現在の行動へのつながりを含むかどうかのみを変更する。

表示位置による偏りを小さくするため、

画面上の左右（上下）の表示順は回答者ごとにランダム化する。

---

# 観察項目

## 主指標

- どちらと続きを話したいか（強制選択）

## 補助観察

- 選択理由（自由記述）
- 実験中に分かりにくかった点（任意）
- 回答時間
- 表示順

好意、尊敬、信頼、心理的近接性は本実験では直接測定しない。

---

# 成功条件

次のいずれかを確認できれば、

本実験は実施した価値があったと判断する。

- 5人中4人以上が条件Bを選ぶ。
- 自由記述に「人柄が見える」「背景が気になる」「もっと知りたい」に相当する理由が現れる。
- 仮説を修正する必要のある反応が見つかる。
- 実験環境の改善点を一つ以上発見できる。

この基準は効果の証明ではなく、

別の記憶刺激で再現実験へ進む価値の判定に使う。

---

`web/exp-0003/index.html` をブラウザで開く。

回答は外部へ自動送信されず、使用中のブラウザにのみ保存される。

同じ端末を5人へ順番に渡す方式で実施し、

最後に「結果をJSONで保存」から全回答を取得する。

# 新しい問い

- 選ばれた理由は Memory Selection そのものか、道徳的な行動の好ましさか。
- 別の価値観や、好ましくない記憶選択でも同じ効果が生じるか。
- 「続きを知りたい」は Biographical Resonance の初期反応として妥当か。

---

# 制約

本実験は最小の探索実験であり、

条件Bは条件Aより文章が長く、情報量も多い。

また、浜辺のごみを拾う行動の道徳的な好ましさが、

Memory Selection とは独立に選択へ影響する可能性がある。

したがって結果は Memory Selection の効果の証明とは扱わず、

次の統制された刺激を作る価値があるかの判断に限定する。

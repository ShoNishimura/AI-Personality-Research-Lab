# EXP-0002

# 同じ出来事の評価差は、残る記憶を変えるのか

**日付**

2026-08-10

**状態**

実施可能

---

# 目的

Character Layerの「知覚・評価 → 感情 → 主観的記憶」を、1つのEventで最小観察する。

# 研究課題

同じEventを異なる初期気質のCharacterが経験したとき、
知覚・評価の差は、感情とMemory Candidateの差として残るか。

# 実験条件

- Character：初期気質だけが異なる2体
- World、Event、事前Memory：同一
- Event：日常的で、正解や道徳的優劣のない1件
- Step：1

# 観察項目

- 知覚・評価
- 感情
- Memory Candidate
- 各出力間の根拠
- Missing Information

# 成功条件

- Memory Candidateの差を知覚・評価または感情の差まで追跡できる。
- 差が生じない条件、または観察形式の改善点を1つ以上発見できる。

# 制約

Creatorは感情や記憶を直接指定しない。
本実験では信念、動機、関係性、人格更新を結論づけない。

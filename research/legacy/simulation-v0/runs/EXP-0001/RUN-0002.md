# Analysis

RUN-0001 と同様に、

P-0001 と P-0002 は

同一の Event に対して

異なる Interpretation を行った。

今回の Event は

「別れ」よりも日常的な出来事であり、

World の情報が少なくても

Simulation Engine は比較的一貫した判断を行うことができた。

また、

P-0001 は相手への信頼を維持する方向へ、

P-0002 は相手への警戒を強める方向へ

Memory Candidate を形成した。

これは、

気質が

Memory Selection にも影響している可能性を示唆している。

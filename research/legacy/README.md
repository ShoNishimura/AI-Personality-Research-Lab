# Legacy Research Archive

このディレクトリには、現行のAPRL Research Framework / Research Modelと一致しない旧資料を隔離して保持する。

Legacyは研究史、監査、再解釈のために保存するが、現行仕様・現行実験の根拠として直接使用しない。

## Archive map

| Directory | Scope |
|---|---|
| `pre-canonical/` | 公開Canonical体系確立前の初期Docs、Notes、Discovery |
| `canonical-v1/` | 旧 `T0=(S,N,C)` を用いたcanonical-v1実験系列 |
| `concept-model-v1/` | 単一Concept Modelから二段構造へ移行する直前の正本 |
| `simulation-v0/` | さらに以前のLegacy Simulation |

現行の入口は [`../../README.md`](../../README.md) と [`../../docs/README.md`](../../docs/README.md) を参照する。

Legacy資料を現行研究へ戻す場合は、そのまま復活させず、現行Framework / Modelとの整合を確認した新しいNoteまたはExperimentとして扱う。

# APRL Concept Model v1 Archive

このディレクトリは、APRLを単一のConcept Modelで記述していた最終版を研究史として保持する。

`APRL_Concept_Model_v1.0_Canonical_Edition.md` は内容を変更せず保存する。2026-08-12の再編以降は正本ではない。

現行正本は次の二段構造である。

1. [APRL Research Framework v1.0](../../../docs/APRL_Research_Framework.md)
2. [Personality Formation Model v1.0](../../../docs/models/Personality_Formation_Model.md)

## 旧章の移管先

| 旧 Concept Model v1.0 | 現行の移管先 |
|---|---|
| 1. Purpose | APRL Research Framework |
| 2. Vision / Mission / Grand Research Question | APRL Research Framework |
| 3. Core Philosophy | APRL Research Framework |
| 4. Core Model | Personality Formation Model。Biographyへの接続だけはFrameworkとの境界として扱う |
| 5. Temperament | Personality Formation Model |
| 6. Interpretation | Personality Formation Model |
| 7. Regulation | Personality Formation Model |
| 8. Response | Personality Formation Model |
| 9. Biological Applicability | Personality Formation Model |
| 10. Relationship | APRL Research Framework。人格形成への影響はFormation Modelの境界として扱い、詳細機構は将来のRelationship Model候補 |
| 11. Character and Biography | APRL Research Frameworkが概念を定義し、Personality Formation Modelが形成過程からBiographyへの接続を説明 |
| 12. Creator / Communicator / Audience | APRL Research Framework |
| 13. Story Emergence | APRL Research Framework |
| 14. Formation and Observation | Personality Formation Model |
| 15. Theoretical Basis | Personality Formation Model |
| 16. Canonical Statement | 上位Frameworkと下位Formation Modelへ分割して置換 |
| Version | 各正本が独立してversioning |

この仕分けにより、**APRL全体の研究地図**と、**直近で検証する人格形成の詳細モデル**を分離する。
